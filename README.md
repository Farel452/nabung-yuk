## Features & Capabilities
- **Net Worth & Balance Overview:** Real-time summary of total net balance, income, and expenditure with dynamic month-over-month growth indicators.
- **Monthly Growth Metrics:** Dedicated analytics cards tracking net savings, budget usage percentage, total invested capital, and total transaction volume.
- **Smart Currency & Zero-State Formatting:** Custom utility functions to gracefully format currency figures and handle zero-balance states without layout glitches.
- **Modern Dark-Themed UI:** High-contrast, clean aesthetic designed for effortless visual scanning and optimal user experience.
- **Modular Component Architecture:** Scalable front-end structure built with Vue.js for easy state management and API integration.
